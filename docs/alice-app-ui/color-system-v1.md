# Alice アプリ カラーシステム v3

## 基本方針

白〜ごく薄いグレーを主なキャンバスにし、明るいロイヤルブルーをUIの中心にする。水色・薄紫・黄色は、感情やAliceの反応を伝える小さなアイコンだけに使う。グラデーションは使用しない。AliceとHarryの衣装色はキャラクター固有色として変更しない。

## カラートークン

| 用途 | 色 | HEX |
|---|---|---|
| ブランド／主要操作 | ロイヤルブルー | `#3568F4` |
| CTAの立体影 | ダークブルー | `#2455D9` |
| 補助要素 | ライトブルー | `#8FC9FF` |
| 見出し／本文 | ディープネイビー | `#172A63` |
| 選択背景 | ペールブルー | `#EEF3FF` |
| 感情アクセント | ソフトラベンダー | `#CDB4FF` |
| 達成アクセント | ソフトイエロー | `#FFD76B` |
| 基本背景 | ホワイト | `#FFFFFF` |
| 外側背景 | オフホワイト | `#F7F7F8` |
| 非アクティブ | ニュートラルグレー | `#9BA3B4` |
| 境界線 | ライトグレー | `#E5E7EB` |

## 使用ルール

- 画面背景は原則ホワイト。
- 主要CTAは単色の `#3568F4`。
- CTA下部に単色の `#2455D9` を別レイヤーとして置き、立体感を出す。
- アクティブなナビゲーション、進捗、構造情報、主要アイコンはブルー。
- 選択状態はブルーの枠線とペールブルーの背景で表現する。
- 水色・薄紫・黄色は、ハート、星、感情、完了演出などの小さな要素に限定する。
- アクセント色をCTA、見出し、ナビゲーション、広い背景には使用しない。
- 非アクティブ状態や感情差の補助にはニュートラルグレーを使用する。
- 本文はディープネイビーを使用する。
- キャラクター画像の紫や金は公式キャラクターの一部として例外扱いにする。
- グラデーション、発光、色付きのぼかし影は使用しない。
