# 表示サイズに合わせた画像配信（2026-09-30）

## 変更

タイプ一覧と相性ページの Next.js Image に、CSSの実際の表示幅に一致する `sizes` を設定した。ブラウザが画面幅・画素密度に応じた画像を選択できるようにする。

- `src/components/types/TypesGalleryPage.tsx`: 1／2／4列のグリッド、余白、列間隔、スマートフォンの最大420pxに対応。
- `src/components/aisho/AishoPage.tsx`: ヒーロー、選択済みキャラクター、一覧サムネイル、分析中キャラクター、結果ランク、代替画像に対応。
- 日本語・英語・韓国語・インドネシア語の共通コンポーネントへ適用。

元画像、画像品質設定（75）、CSSレイアウト、読み込み優先度、料金・購入処理は変更していない。課金画面の初期読み込みも維持する。削減対象は画像転送量で、画像リクエスト件数自体は減らない。

## 実測

ローカルの本番ビルドをChromeの新規コンテキストで比較。タイプ一覧は32画像、相性ページはヒーローと一覧の33画像をすべて取得した。値は最適化画像のレスポンス本文の合計で、ヘッダー・JavaScript・フォントを含まない。画面外の画像も取得する条件なので、初期表示だけの転送量とは異なる。

| ページ | 画面幅／画素密度 | 変更前 | 変更後 | 削減率 |
| --- | --- | ---: | ---: | ---: |
| タイプ一覧 | 390px／2倍 | 3,681,330 B | 2,154,556 B | 41.5% |
| タイプ一覧 | 1440px／2倍 | 3,681,330 B | 2,154,556 B | 41.5% |
| 相性 | 390px／2倍 | 678,348 B | 355,270 B | 47.6% |
| 相性 | 1440px／2倍 | 678,348 B | 368,934 B | 45.6% |
| タイプ一覧 | 430px／3倍 | 3,681,330 B | 3,681,330 B | 0% |
| 相性 | 430px／3倍 | 678,348 B | 373,794 B | 44.9% |

例として、390px・2倍のタイプ画像は要求幅1080pxから750px、相性の一覧顔画像は384pxから256px、相性ヒーローは3840pxから750pxになった。

高画素密度の端末では必要な解像度を優先する。430px・3倍のタイプ一覧は、変更前後とも元画像の1024pxを上限とした配信になり、転送量は変わらなかった。端末・キャッシュ・閲覧範囲で効果は異なり、この削減率が請求全体の削減率になるわけではない。
