# 商品・価格カタログ

状態: 固定
固定日: 2026-09-17
変更権限: ユーザーによる明示的な事業判断がある場合のみ

この文書は、現在販売する商品と価格を固定するための事業上の一覧である。実際のCheckout金額と権利判定は、`src/lib/access-products.ts`、`src/lib/line-plus-products.ts`、およびサーバー側Checkout実装を正本とする。

## 1. 固定方針

- 商品数、商品内容、価格、課金形態、trial期間を変更しない。
- 2026-09-17に明示承認された日本語版完全版の「通常価格¥1,290／リリース記念−¥791／請求額¥499」、同一商品・同一JPY価格のインドネシア語版、英語版Complete Editionの「通常価格$12.90／Release offer −$7.91／請求額$4.99」表示を維持し、それ以外の値引き、期間限定セール、価格A/Bテスト、コース追加・削除を行わない。
- 表示コピー、導線、デザインは、商品内容と価格を変えない範囲で改善できる。
- 既存購入者の権利互換と返金処理は維持する。
- Stripe Dashboard上のPriceは直接変更せず、コードが期待する金額・通貨・課金形態と一致させる。
- 変更が必要になった場合は、先に `BUSINESS_CONSTITUTION.md` と本文書を更新し、新しい計測バージョンを発行する。

## 5. 既存購入者向け互換

- 過去の購入時に約束した権利を縮小しない。
- 現在の公開商品に含まれない旧商品キーや価格定数は、販売目的ではなく、権利復元・返金・監査のために保持する。
- 差額購入を維持する場合も、新規ユーザー向けの商品として露出しない。
- 返金後は、残っている有効な購入履歴だけから権利を再計算する。

## 6. 固定中に確認する指標

商品・価格を動かさず、次を同一条件で観測する。

- Web: 診断完了からペイウォール閲覧、購入CTA、Checkout到達、購入完了までの転換率。
- 商品別: 購入者数、純売上、返金率、ARPU。
- Alice Plus: trial開始、加入、継続、解約、MRR。
- 国・流入元・商品・ペイウォールバージョン別の差。

価格や商品を再検討する場合は、観測期間と判断指標を先に決め、固定解除を明示する。
